# v1.4 Release Summary - Image Details Inspector

This release introduces significant updates focusing on positioning accuracy, enhanced image metadata, and a more robust architectural foundation.

---

### **Major Highlights**

#### **1. Advanced Penalty-Based Positioning Engine**
*   **Intelligent Placement**: Replaces simple viewport checks with a sophisticated scoring system (`resolveInfoBoxPlacement`) that evaluates multiple candidate locations (top, bottom, left, right).
*   **Overlap Avoidance**: Prioritizes placement that avoids obscuring the source image, other images on the page, or existing overlays.
*   **Layout Awareness**: Automatically detects `flex` and `grid` parent containers to prefer side-gutter placement, improving visibility in complex web layouts.

#### **2. Enhanced Image Metadata & Transfer Insights**
*   **Background Fetching**: A new tiered fetching strategy in the background service worker (HEAD → Range GET → Full GET) bypasses content script limitations to retrieve accurate file sizes and MIME types.
*   **Performance Metrics**: Overlays now display browser-level optimization hints, including **Loading Strategy** (`lazy` vs. `eager`) and **Fetch Priority**.
*   **Host Permissions**: Added `<all_urls>` host permissions to ensure the extension can reliably fetch metadata for images across all domains.

#### **3. Visual & UI Improvements**
*   **Visual Association**: Introduces color-matched "Association Borders" (3px solid) that surround the source image, clearly linking it to its corresponding information overlay.
*   **Grid Layout**: The overlay UI has been redesigned using a dense CSS grid for better readability of technical specs (Type, Size, Loading, etc.).
*   **UI Hierarchy**: Added uppercase transformations and subtle borders to grid headers for improved visual structure.

---

### **Technical Refactoring**

*   **Shared Overlay API**: Consolidated overlay rendering logic into `imageDetails.js`, exposing a shared API (`window.imageDetailsAPI`) used by both Show All and Inspector modes.
*   **Slimmer Inspector Mode**: `inspectorMode.js` has been refactored to delegate all rendering to the shared API, ensuring perfect visual consistency across the entire extension.
*   **Efficient Refresh Logic**: Implemented a pre-calculation step for image rectangles during bulk refreshes to avoid O(N²) layout thrashing on image-heavy pages.
*   **State Management**: `inspectorMode.js` now uses a `WeakSet` to track and prevent duplicate event listener attachments, improving performance on dynamic pages.

---

### **Documentation**
*   **README Update**: Fully updated to reflect the new 1.4 features, including the new information display format and the technical details of the positioning engine.
